# CheckCompany
> 현실 목표를 달성하면서 성장하는 자기개발 회사 경영 시뮬레이션 게임


# 프로젝트 소개
> 당신의 목표가 곧 회사의 미래입니다.
현실의 목표를 게임 속에서 달성하며 회사를 성장시켜 보세요. 실제 업무, 개인적인 도전, 심지어 취미까지! 당신의 모든 목표가 회사의 자산이 됩니다. 목표를 이룰 때마다 회사의 재정이 늘어나고, 새로운 팀원을 고용하며, 더 큰 사무실로 확장하는 성취감을 느껴보세요. 현실의 노력이 게임 속 성과로 이어지는 특별한 경험이 당신을 기다립니다. <br><br>
<img width="407" height="882" alt="image" src="https://github.com/user-attachments/assets/ca5c684f-bb9f-4808-af8d-f0fa84755754" /><br>

CheckCompany는 자기개발 회사 경영 시뮬레이션 게임입니다. <br>
현실 속 목표 달성이라는 행위를 게임의 핵심 성장 요소로 삼아, 플레이어에게 지속적인 성취감과 동기를 부여하도록 설계되었습니다. <br>


## 기능
### 서버
- 로그인 로그아웃 기능
- 데이터 입출력 (직원, 목표)

### 클라이언트
- 직원 시스템 (고용, 해고)
- 미션 시스템 (생성, 달성, 삭제)

## 기간
2024년 2월 ~ 2025년 8월 (1년 6개월)

## 인원
1인 개발

## 목적
평소 목표 달성 서비스에 대한 관심과 타이쿤 장르의 재미를 결합해보고자 직접 기획 및 구현을 시작했습니다.
