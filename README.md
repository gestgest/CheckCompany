## 📖 프로젝트 소개

**CheckCompany**는 자기개발 회사 경영 시뮬레이션 게임입니다.
현실 속 목표 달성이라는 행위를 게임의 핵심 성장 요소로 삼아, 플레이어에게 지속적인 성취감과 동기를 부여하도록 설계되었습니다.

현실의 목표를 게임 속에서 달성하며 회사를 성장시켜 보세요.
실제 업무, 개인적인 도전, 심지어 취미까지 — 당신의 모든 목표가 회사의 자산이 됩니다.

- ✅ 목표를 이룰 때마다 회사의 **재정 증가**
- 👥 성과에 따라 **새로운 팀원 고용**
- 🏙️ 회사를 **더 큰 사무실로 확장**

현실의 노력이 게임 속 성과로 이어지는 특별한 경험이 당신을 기다립니다.

## ✨ 주요 기능

### 🖥️ 서버
- 로그인 / 로그아웃 기능
- 데이터 입출력 (직원, 목표)

- **직원 시스템**: 고용, 해고
- **미션 시스템**: 생성, 달성, 삭제
